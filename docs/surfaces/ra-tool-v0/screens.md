# 화면 설계서 — AI Research Center

> 목업의 TSLA 숫자는 `../src/examples/facts/TSLA.json` fixture의 실제 `display_value`입니다. 임의 값이 아니므로 구현 시 그대로 대조할 수 있습니다.

## 0. 설계 기준

### 이 제품의 UI가 해야 하는 일

일반 SaaS와 다른 요구가 하나 있습니다. **신뢰를 눈에 보이게 만들어야 합니다.**

RA는 이미 ChatGPT를 씁니다. 문장 품질로는 차별화되지 않습니다. 차별점은 "이 숫자를 믿을 수 있다"인데, 그건 기능이 아니라 **경험**이어야 합니다. 그래서:

1. **모든 숫자는 클릭 가능해야 합니다.** 출처를 1클릭 안에 보여주지 못하면 제품의 존재 이유가 사라집니다
2. **비어 있는 것을 숨기지 않습니다.** `omitted`와 `coverage: limited`를 회색 빈칸이 아니라 명시적 상태로 표시합니다
3. **검증 게이트가 작동하는 것을 보여줍니다.** 재생성을 로딩 스피너 뒤에 숨기지 않습니다

### 공통 컴포넌트

| 컴포넌트 | 용도 | 동작 |
|---|---|---|
| **Fact Chip** | 숫자 표시 | 밑줄 있는 인라인 배지. 클릭 → Source Popover |
| **Source Popover** | 출처 표시 | 값 / 단위 / `formula` / 입력값 / accession·접수번호 / 공시 URL |
| **Coverage Banner** | 제한 커버리지 | `limited`일 때 화면 상단 고정. 무엇이 왜 비었는지 |
| **Omitted List** | 누락 항목 | 접힌 상태로 표시, 펼치면 지표·연도·이유 |
| **Severity Tag** | 프리체크 심각도 | `critical` / `high` / `medium` 색상 구분 |
| **Boundary Notice** | 경계 고지 | `발행 전 프리체크 · 준법감시인 심사를 대체하지 않습니다` — 프리체크 UI에 상시 |
| **AI Attribution** | AI 생성 표시 | `AI 생성` / `사람 입력` 배지. 의견 필드는 항상 후자 |

### 좌측 패널 — 앵글 · 목차 · 팩트 팔레트

- **앵글 후보**: `core/packet.py`의 `build_angle_candidates`가 생성. 선택 시 본문 재생성
- **목차**: 앵글의 `development` 배열에서 파생
- **근거 팩트**: fact 카탈로그. 드래그해서 본문에 삽입 → 토큰이 자동 삽입됨
  - 사용자가 손으로 숫자를 타이핑하는 대신 팩트를 드래그하게 만드는 것이 원칙 1의 UX 측면

### 중앙 — 에디터

**Fact Chip 렌더링**이 핵심입니다.

- 본문 저장 형태는 `{{fact:sec:TSLA:FY2025:operating_margin_bridge.operating_margin_change}}` (토큰)
- 화면 렌더링은 `⟨-2.7pp⟩` (밑줄 + 미묘한 배경색)
- 클릭 → Source Popover
- 사용자가 chip을 지우면 토큰이 함께 지워짐 (숫자만 남는 상태 불가)
- 사용자가 손으로 숫자를 타이핑하면 → 저장 시 게이트가 잡아서 경고

**게이트 로그 표시**

재생성을 숨기지 않습니다. 인라인으로:

```
⟳ 게이트 재생성 1회 (미바인딩 숫자 "약 3%" 감지 → fact 토큰으로 교체)
```

이걸 보여주는 이유: 제품의 신뢰 메커니즘이 실제로 작동하는 것을 사용자가 보게 됩니다. 숨기면 "그냥 느린 ChatGPT"로 보입니다.

### 우측 패널 — 컴플라이언스 · 의견

- **실시간 프리체크**: `POST /precheck/inline`을 디바운스(700ms)로 호출. 문장 단위(`iter_segments`) 검사
- finding 카드에 심각도 / 카테고리 / 검출 문구 / 이유 / 법령 매핑 / 제안 문구
- `[적용]` 버튼으로 `safer_rewrite`를 본문에 반영
- **Boundary Notice 상시 표시** — 원칙 4
- **투자의견 슬롯**: 항상 `사람 입력 전용` 라벨. AI가 채운 상태가 존재할 수 없음

### 상태

| 상태 | 표시 |
|---|---|
| 최초 진입 (본문 없음) | 앵글 선택 유도. "앵글을 선택하면 초안을 생성합니다" |
| 생성 실패 (게이트 2회 초과) | 본문은 보여주되 위반 위치를 빨간 밑줄로 표시. "수동 확인 필요" |
| fact 스냅샷이 갱신됨 | 배너: "새 공시가 있습니다. 팩트를 갱신하면 현재 초안의 숫자가 재검증됩니다" |
| LLM API 오류 | "생성 실패 (재시도)". 작성 중이던 본문은 보존 |
| 프리체크 0건 | ✓ 초록. 단 "심사 대체 아님"은 계속 표시 |

## 8. 테마 보드 `/board` [Phase 3]

`core/board.py`가 이미 생성하는 6개 섹션을 그대로 화면화합니다.

```
Scope & Universe → 핵심 운영지표 → Operating Comps Snapshot
→ Landscape (클러스터) → 콘텐츠 아이디어 Shortlist → 다음 행동
```

**중요**: Shortlist의 점수는 `editorial_priority_score`이며 **투자 매력도가 아닙니다.** 화면에 `편집 우선순위 · 투자추천 아님`을 명시합니다. `boundary.ranking_basis` 배열을 툴팁으로 노출해 어떤 신호로 계산됐는지 보여줍니다.
