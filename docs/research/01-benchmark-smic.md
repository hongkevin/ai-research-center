## 0. 결론 먼저

**제 기존 설계는 리포트의 산출물을 겨냥했지만, RA의 노동은 그 앞단에 있습니다.**

| | 제 설계가 다루던 것 | 벤치마크가 실제로 하는 것 |
|---|---|---|
| 시간축 | 과거 확정 실적 검증 | **향후 3년 추정** (26E/27E/28E, 15/15건) |
| 산출물 | 초안 문장 | **3표 완전 추정 모델** + 밸류에이션 → 목표주가 |
| 출발점 | 손익계산서 지표 변화 | **매크로·정책·산업 서사** → 종목으로 하강 |
| 숫자 범위 | 전사 9개 원시 지표 | 세그먼트·제품별·unit economics |

리포트는 **결과물**이고, 모델이 **작업**입니다. 저는 결과물만 도우려 했습니다. 그래서 돈을 낼 이유가 약했던 것입니다.

### 발견 1 — 해외 종목의 60%가 SEC 밖입니다

제 설계는 SEC EDGAR + DART입니다. 그런데 해외 5건 중 3건이 파리·프랑크푸르트·타이베이 상장사입니다. **SEC에 파일링이 없습니다.**

RA가 커버하는 해외 종목은 미국주식이 아니라 **글로벌 밸류체인의 병목 기업**입니다. AI 인프라를 파고들면 유럽 장비사(Aixtron, Soitec)와 대만 디자인하우스(GUC)로 갈 수밖에 없습니다. 미국 상장사만 커버하는 도구는 이 리서치를 지원할 수 없습니다.

이건 제 커버리지 전략의 근본 결함입니다. [00-PRD.md](../surfaces/ra-tool-v0/prd.md)에서 "해외주식 담당 RA"를 핵심 타겟으로 잡고 SEC로 충분하다고 가정했는데, 틀렸습니다.

## 3. 두 개의 테마 클러스터 — 거의 배타적

계량 결과 두 군이 뚜렷하게 갈리고, 서로 섞이지 않습니다.

### A군: AI 인프라 병목 (9~10건)

나노 · Sterling · Comfort Systems · Soitec · Aixtron · HD현대마린솔루션 · 샘씨엔에스 · Global Unichip · 코스텍시스

- 지표: `병목`이 이 군에 집중 (Comfort 77회, Sterling 41회, GUC 37회)
- 논리 구조: **AI DC 수요 → 밸류체인 병목 지점 특정 → 그 지점을 장악한 기업**
- 밸류에이션: PER 중심
- 대표 프레임: "공급 증가가 어렵기에 수요 대비 공급부족이 지속되며, P와 Q가 동반 상승하고 EPS가 주가의 정당성을 입증한다"

### B군: 밸류업·지배구조 (5건)

F&F홀딩스 · 파트론 · 코오롱인더 · 금화피에스시 · 농심홀딩스

- 지표: `배당` 317회, `승계` 191회, `주가누르기` 101회가 전부 이 5건에 집중
- 논리 구조: **정책 변화(상법 개정·주가누르기방지법) → 승계 유인 구조 변화 → 배당/주주환원 확대 → PBR 정상화**
- 밸류에이션: PBR + SOTP + 할인율 역산
- A군 지표(병목)가 거의 0

### 발견 2 — 리포트는 손익계산서에서 출발하지 않습니다

**이게 제 설계의 가장 큰 오류입니다.**

제 `single_stock_packet.py`는 손익계산서 지표 변화에서 앵글을 만듭니다. 그래서 NVDA FY2025(매출 폭증)와 TSLA(마진 하락)가 **글자까지 동일한 앵글 3개**를 받습니다.

실제 리포트는 반대 방향입니다:

```
매크로/정책 서사  →  산업 구조 (밸류체인·병목)  →  종목 선정  →  재무 추정  →  밸류에이션
     ↑                                                              ↑
  출발점                                                    제 설계가 시작하는 곳
```

재무 지표는 **논지의 증거**이고 출발점이 아닙니다. 앵글 생성기를 재무제표에 붙여둔 한 템플릿을 벗어날 수 없습니다.

## 4. 밸류에이션 로직 해부 — 어디까지 계산이고 어디부터 판단인가

두 대조 사례를 정밀 해부했습니다. **[06-VALUATION.md](../research/03-valuation-boundary.md)의 경계 재설계 근거입니다.**

### 사례 A — Global Unichip (성장주, PER)

논리 사슬:

1. 2027E EPS를 추정 (TWD 143.73) ← **추정 모델 산출물**
2. Target PER을 **자기 과거 12M Fwd PER 밴드의 특정 구간 평균**에서 차용 (53.40x / 59.91x)
3. 그 구간을 고른 근거는 **"두 시기 간 상황적 유사성"** — 당시 시장이 반영하던 기대와 27년 기대가 유사하다는 논증
4. EPS × Target PER = Target Price → 상승여력 67.5%
5. 시나리오 2개: HBM 매출 반영(59.91x) / 미반영(53.40x)
6. Appendix에 12M Fwd PER 밴드 차트 + 추정 BS·CF

**결정적**: Target Multiple의 근거가 peer 비교가 아니라 **자기 역사적 밴드**입니다. 밴드를 그리고 구간 평균을 뽑는 건 100% 결정론적 계산입니다. 판단은 **"어느 구간이 유사한가"** 하나뿐입니다.

### 사례 B — 금화피에스시 (자산주, PBR + SOTP)

논리 사슬:

1. **PBR = PDR × ROE × 배당성향** 으로 분해하고 각 구성요소를 따로 논증
   - 배당성향: Case 1은 25%→43% 점진 확대, Case 2는 25% 고정
   - ROE: 배당액이 BS에 반영되면 **자동 계산** (10%)
   - Target PDR: 20x (배당수익률 5%) — 밸류업 기업군 관행에서 차용
2. SOTP로 별도 산출하고 **두 방법을 교차 검증** (SOTP 52,450 vs PBR 53,400 → 52,900 채택)
3. 과거 영업가치의 **내재 할인율을 역산** (34.4%)
4. Case 분기가 **정성 이벤트에 연동**: ① 누르기방지법 통과 ② 유예기간 중 증여 무산
5. 연도별 목표주가 경로 (26.06 / 27.12 / 28.12)

**결정적**: 시나리오 분기는 사람 판단이지만, **분기를 정한 뒤의 모든 숫자는 결정론적 계산**입니다. ROE는 "자동으로 계산되게 된다"고 리포트가 직접 말합니다.

## 5. 추정 모델의 실제 정밀도

샘씨엔에스 부록 구조를 보면 RA의 노동 강도가 드러납니다. 부록이 **11개 이상**입니다:

| 부록 | 내용 |
|---|---|
| Appx 1 | 주가 및 PER 밴드 |
| Appx 4 | **Wafer 1장당 동사 매출액** ← unit economics |
| Appx 7 | **사용권자산상각비 추정** |
| Appx 11 | **기타 자산 및 부채 추정** (기타유동금융자산, 기타비유동금융자산) |
| — | 추정 재무상태표 · 현금흐름표 |

**사용권자산상각비와 기타유동금융자산까지 추정합니다.** 이건 3표 완전 모델입니다. 손익만이 아니라 BS·CF를 연결해서 돌립니다.

금화피에스시는 여기에 **자회사별 추정**까지 더합니다 (Appx 2. 금화ETC 및 금화정수 추정 재무상태표 및 현금흐름표).

### 이게 제품의 핵심 기회입니다

이 작업은:
- **반복적입니다** — 분기마다 실적이 나오면 전부 갱신
- **오류가 잘 납니다** — 셀 하나 틀리면 목표주가까지 전파
- **연결되어 있습니다** — 드라이버 → 손익 → BS → CF → ROE → PBR → 목표주가
- **검증 가능합니다** — 3표가 서로 맞아야 함 (제 마진 브리지 `reconciliation`과 같은 성질)

그리고 현재 엑셀로 하고 있습니다.

### 가장 중요한 발견 — 제가 금지한 것이 공시에 있습니다

현재 `single_stock_packet.py`의 `avoid_overclaims`는 이렇게 말합니다:

> "AI 수요가 폭발해서 매출이 늘었다" — 수요 원인은 공시 본문, 실적 발표, 경영진 발언 등 별도 출처가 필요합니다.

**그 별도 출처가 같은 SEC 안에 있습니다.** NVDA 실적발표 Outlook 섹션에서 경영진이 직접:

- 매출 가이던스와 **그 원인**을 함께 명시 (수출규제로 인한 특정 규모의 매출 손실)
- 총이익률 가이던스 + 목표 구간과 시점
- 영업비용 가이던스 + 연간 증가율 전망

금지할 게 아니라 **인용하면 되는 것**이었습니다. 라이선스 비용 0원, 1차 출처, 인용 가능.

### CFO Commentary의 세그먼트 데이터

NVDA 사례에서 Data Center를 Compute/Networking으로 쪼갠 매출과 각각의 QoQ·YoY가 표로 제공됩니다. §2에서 확인한 "세그먼트 15/15건 필수"를 이 소스가 직접 충족합니다.

### 다만 — 본문 섹션 경계 탐지는 실제 작업이 필요합니다

10-K에서 Item 7(MD&A)을 뽑으려다 **첫 시도에 실패**했습니다. 순진한 `^Item 7\.` 정규식은 목차(offset 24,212)를 잡고 본문(offset 205,719)을 놓쳤습니다. 제 최초 계산은 MD&A를 223,226자로 봤는데 실제로는 약 38,000자였습니다.

원인과 대응:

| 문제 | 대응 |
|---|---|
| 목차와 본문에 같은 문자열이 등장 | 다음 Item 앵커(7A)로 역방향 탐색 + 표 셀 구분자(`|`) 유무로 목차 판별 |
| 아포스트로피 인코딩 불일치 (U+2019 vs ASCII) | 정규화 후 매칭 |
| 표 셀 분할로 헤딩이 쪼개짐 | 복수 헤딩 패턴 + 줄바꿈 무시 매칭 |

**"쉽다"고 쓰면 안 되는 항목입니다.** 실측했기에 압니다.

### 소스 우선순위 수정

§2의 "컨콜은 5/15건뿐" 발견과 합치면:

| 순위 | 소스 | 근거 | 비용 |
|---|---|---|---|
| 1 | **8-K 실적발표 + CFO Commentary** | 세그먼트(15/15 필수) + 가이던스(10/15) 동시 충족. `items=2.02`로 정확 식별 | 0 |
| 2 | **10-K MD&A / Item 1A** | 경영진 원인 설명. `avoid_overclaims` 해소 | 0 (경계 탐지 작업 필요) |
| 3 | 세그먼트 XBRL | 구조화 데이터. 8-K와 교차검증 | 0 |
| 4 | 가격·밸류에이션 데이터 | PER/PBR 밴드에 **필수** (§4) | 유료 |
| 5 | 컨퍼런스콜 전사 | 8회 5/15건뿐 — **우선순위 하향** | 유료·고가 |

4번이 승격됐습니다. 밸류에이션 밴드를 그리려면 과거 주가 시계열이 반드시 필요하고, §4에서 그게 Target Multiple의 근거임이 확인됐습니다.

## 7. 분석의 한계

| 한계 | 영향 |
|---|---|
| 표 추출이 깨짐 | 재무제표·밸류에이션 표의 숫자를 계량하지 못함. 문자 단위로 파편화(`자 산 총 계`, `4 0 7 ,0 8 7`) |
| 차트 미분석 | 밴드 차트·워터폴 등 시각 자료의 비중과 종류를 세지 못함 |
| 주장-근거 전수 코딩 미완 | 합의한 E1~E7 전수 추출은 표 문제로 부분만 수행. §2 계량이 대리 지표 |
| 최우수 RA 리포트 미확보 | 동아리 리포트만 분석. "노력 vs 통찰" 대조를 못 함 |

**표 추출 실패 자체가 제품 함의를 가집니다.** 리포트 PDF에서 표를 자동으로 읽는 게 어렵다면, 반대로 **표를 구조화된 데이터로 생성해주는 것**이 그만큼 가치입니다. RA가 엑셀에서 만들고 PDF로 굳히는 그 표를, 처음부터 데이터로 다루는 도구.

## 8. 다음에 필요한 자료

이번 분석은 "심혈을 기울인 것"의 표준을 보여줬습니다. 아직 못 본 것:

| 필요 자료 | 이 자료로만 답할 수 있는 질문 |
|---|---|
| **최우수 RA 리포트 5~10건** | 노력과 통찰의 차이. 동아리 리포트가 채우지 못한 것은 무엇인가 |
| **최우수 선정 사유 텍스트** | 업계가 명시적으로 무엇을 "좋다"고 하는가 |
| 평범한 증권사 리포트 1~2건 | 하한선. 자동화가 대체할 수 있는 수준 |

특히 리스크·시나리오·민감도가 동아리 리포트에서 약했는데(§2), 최우수 리포트에서 강하다면 그게 **차별화 요소**이고 제품 기능 후보입니다.
