# AI Research Center — 설계 결정 브리프 (v1, 2026-07-25)

## 1. 한눈 요약

- **기회는 명확하다**: 코스닥 상장사 약 60%가 연간 리포트 0건인 커버리지 공백이 구조적으로 존재하고([헤럴드경제](https://biz.heraldcorp.com/article/10770589)), 한투 AIR가 미커버 523개사 분석으로 이 공백의 수요를 실증했다([그린포스트코리아](http://www.greenpostkorea.co.kr/news/articleView.html?idxno=205689)). 그런데 "미커버 중소형주 대상 완결형 종목 보고서 상시 발간" 포지션은 국내에 사실상 비어 있다(조사 3).
- **규제가 제품 설계를 결정한다**: '조사분석자료' 해당 여부는 ①금융투자회사 명의인가 ②가치 주장·예측 포함인가 ③공표/제3자 제공인가의 3요소로 갈리며, 개인 개발자는 이 3요소를 제어해 규제 밖에서 시작할 수 있다(조사 5). 단, 투자의견·단일 목표주가는 v1에서 빼는 것이 정석이다.
- **기술 공식은 이미 검증됐다**: "결정적 Python 계산 + LLM 서술 분리" + "AI 초안 + 인간 검수"가 국내외 공통의 유일한 발간 가능 공식이다(미래에셋·KB·FinRobot, 조사 3·4).
- **추천안**: (b) 세미오토 시스템 — 사용자 본인이 검토 게이트가 되는 무료·일방향 발간으로 시작, 실적 리뷰 노트 × 코스닥 미커버 종목부터. 아키텍처는 파이프라인형(B) + 섹션 병렬 팬아웃 하이브리드, 건당 약 $0.5~1.7(추정).
- **최대 공백 2가지**: 컨센서스 데이터의 합법적 무료 경로 부재(조사 2), 한국어 리포트 품질 평가 벤치마크 부재(조사 6) — 둘 다 MVP 설계에 반영했다.

## 3. 추천 MVP

### 범위: "실적 리뷰/프리뷰 노트" × 코스닥 미커버 종목

- **보고서 유형**: 실적 리뷰(어닝 노트, 2~6p)부터. 입력(공시·잠정실적)과 출력(포맷) 모두 정형적이라 국내외 공통으로 최초 자동화 대상이 된 유형이다(미래에셋 5시간→10~15분, 조사 1·3). 커버리지 개시형 인뎁스는 v2.
- **유니버스**: 코스닥 미커버 중소형주 30~100종목으로 시작. 대형사 AI 리포트가 미국 대형주 실적속보에 몰려 있어 KRX 스몰캡이 상대적 공백 지대(조사 1 §5).
- **출력**: 헤더(기본정보) → 요약 → 투자포인트 2~4개 → 실적 테이블 → **밸류에이션 시나리오(멀티플 범위 × 감도표, 단일 목표주가 아님)** → 리스크 → 디스클레이머(AI 생성물 표시 포함, AI 기본법 제31조).

### 데이터 소스 (무료 조합, 조사 2 결론 채택)

| 용도 | 소스 | 비고 |
|---|---|---|
| 재무·공시 (핵심 기둥) | **OpenDART** (일 20,000건) | 라이선스 리스크 최소. XBRL 재무제표 + 공시원문. 캐싱 전제 |
| 시세 | **금융위 주식시세정보 API** (EOD, D+1, "이용허락범위 제한 없음") | 실적 리뷰는 EOD로 충분. 장중 필요 시 KIS Developers 내부 조회용 병행 |
| 뉴스 | **네이버 뉴스 검색 API** (일 25,000회, 스니펫만) | 본문 크롤링 회피 — 스니펫+공시 원문을 근거로 사용 |
| 배제 | KRX Open API(비상업·재배포 금지), 네이버 금융/FnGuide 크롤링(robots.txt·DB권 리스크) | pykrx/FinanceDataReader 의존 경로는 프로토타입 한정 |

**컨센서스는 MVP에서 제외**하고 자체 밸류에이션(과거 밴드·피어 멀티플)으로 대체 — 합법적 무료 경로가 없다(조사 2 §6). 어차피 타깃이 미커버 종목이라 컨센서스 자체가 없는 경우가 다수라는 점이 이 제약을 완화한다.

### 아키텍처: (B) 파이프라인형 + S4 병렬 팬아웃 하이브리드 (조사 4 권고 채택)

- S1 수집·정규화(코드+haiku) → S2 재무분석(sonnet) → S3 추정·밸류에이션(**결정적 Python finmodel + LLM은 가정 JSON만**) → S4 섹션 병렬 작성(sonnet, thesis.json 주입) → S5 검증 게이트(opus+코드) → S6 렌더링(WeasyPrint).
- 선택 근거: ① 규제 민감 도메인은 자유도보다 **재현성·감사 가능성**이 우선 ② 환각 통제가 파이프라인의 강제 게이트라 LLM이 우회 불가 ③ Batch API 50% 할인으로 건당 ≈$0.5~0.9(배치, 추정) — 단일 에이전트(≈$3.4)나 오케스트레이터-워커(≈$2.5~4.5) 대비 최저 ④ FinRpt(AAAI)·FinRobot 등 학계·오픈소스가 동일 구조로 수렴(조사 4).
- 핵심 설계 원칙(조사 4·6 공통): **모든 수치는 결정적 코드가 계산, LLM은 서술만.** Number Registry 패턴으로 본문 숫자 리터럴을 플레이스홀더 치환 — LLM이 숫자를 지어낼 경로 자체를 차단. FinRobot(Apache-2.0)의 설계를 참조하되 데이터 어댑터는 DART/KRX용 자체 구축 필요.

## 4. 핵심 결정 포인트 (논의 필요 순)

### 결정 1. 목표주가·투자의견을 출력할 것인가 — **조사 간 상충 지점**

- **질문**: 보고서에 단일 목표주가와 Buy/Hold/Sell을 넣을 것인가?
- **상충**: 조사 1은 "리포트의 실질 정보가치는 목표주가·추정치의 변화량과 산출 근거 투명성"이라 하고, 조사 5·6은 "v1에서 제외" — 가치 주장·예측 포함 시 규제 노출이 커지고(투자권유 판단 리스크), 품질 리스크의 교집합이 가장 큰 지점이라는 이유다.
- **옵션**: ① 완전 제외 ② 적정가치 범위(시나리오 3개+감도표) ③ 단일 목표주가 명시.
- **추천**: **② 적정가치 범위.** 산출 산식을 전부 공개("2026E BPS × 밴드 하단~상단 PBR")하면 조사 1이 말한 '근거 투명성' 가치를 확보하면서 단정적 판단 제공 리스크를 회피한다. 추정치 **변화 추적**(전 보고서 대비 EPS 추정 변동)은 목표주가 없이도 구현 가능하며 이것이 진짜 차별화다.

### 결정 2. 배포·수익화 모델

- **질문**: 무료 공개인가, 유료 구독인가, B2B인가?
- **옵션**: ① 무료·일방향(신고 불요) ② 유료 구독(유사투자자문업 신고) ③ B2B 파일럿.
- **추천**: **① 무료·일방향으로 시작.** 인허가 제로에서 발간 실적과 골든셋을 쌓고, 유료화는 유사투자자문업 신고와 함께 별도 결정. **중요 제약: 유료 + 양방향(채팅 Q&A)을 절대 결합하지 말 것** — 투자자문업 등록으로 점프한다(2024.8.14 시행 개정법, 조사 5 §3).

### 결정 3. 첫 보고서 유형

- **질문**: 실적 리뷰 노트 vs 커버리지 개시형 인뎁스 vs 데일리 코멘트?
- **추천**: **실적 리뷰 노트.** 가장 정형적이고(자동화 난이도 하, 조사 1 §5), 어닝시즌마다 자연스러운 발행 리듬이 생기며, 미커버 종목엔 리뷰조차 없어 즉시 가치가 있다. 인뎁스는 파이프라인 검증 후 v2.

### 결정 4. 컨센서스 공백 대응

- **질문**: 컨센서스 비교 섹션을 포기할 것인가, FnGuide 계약을 할 것인가?
- **옵션**: ① 자체 밸류에이션으로 대체(무료) ② FnGuide/QuantiWise 계약(가격 미공개, 1년 해지불가 조항) ③ 한경컨센서스 수동 참조.
- **추천**: **① 대체 후, 유료화 시점을 계약 트리거로 설정.** 미커버 종목 타깃이라 당장의 손실이 작다. FnGuide 계약은 매출 발생 전 개인에게 과도한 고정비.

### 결정 5. 아키텍처 확정과 오픈소스 재사용 범위

- **질문**: §3 하이브리드(B+C)로 확정하는가? FinRobot을 포크할 것인가?
- **추천**: **B+C 하이브리드 확정, FinRobot은 포크 말고 설계 참조만.** FinRobot은 미국 데이터 소스 중심이라 KRX 어댑터를 어차피 새로 짜야 하고(한국 지원 미확인, 조사 3), 핵심 가치는 코드가 아니라 "계산·서술 분리" 원칙이다. 프로토타입 단계에서 단일 에이전트(A, Claude Agent SDK)로 1~2주 내 감을 잡은 뒤 B로 이관하는 것도 유효한 절충.

### 결정 6. 커버리지 규모와 갱신 주기

- **질문**: 몇 종목을 어떤 주기로?
- **옵션**: ① 30종목 어닝시즌 집중 ② 100종목 분기+이벤트 트리거 ③ 전 코스닥(~1,700).
- **추천**: **① → ②.** OpenDART 일 20,000건·비용 월 $200~400(100종목 주 1회, 배치, 조사 4 추정) 한도 내. 전 종목 확장은 KOSAI류 "얕은 대량 생성"과의 차별화를 스스로 훼손하므로 신중히.

### 결정 7. 품질 평가 체계 투자 수준

- **질문**: 골든셋·검증기를 MVP에서 어디까지 만들 것인가?
- **추천**: **G0 하드 게이트(수치 대조 100%, 컴플라이언스 룰 필터, 필수 섹션)는 비타협 — MVP 필수.** grounding 검증(G1)·LLM judge(G2)는 8주차 골든셋 이후 단계적 도입. 한국어(DART 기반) 벤치마크는 전무하므로 골든셋 자체가 이 프로젝트의 핵심 데이터 자산이 된다(조사 6 §6).

## 6. 사용자에게 물어볼 열린 질문

1. **프로젝트의 최종 목표**는 무엇인가 — 포트폴리오/학습, 사업화(B2C 구독? 증권사 제휴?), 아니면 본인 투자 판단용 도구? §4 결정 2의 답이 여기서 갈린다.
2. **금융투자분석사 자격 또는 금융권 경력**이 있는가, 취득 의향이 있는가? 있다면 장기적으로 증권사 제휴·정식 발간 경로가 열린다.
3. **월 예산 상한**은? LLM 비용(추정 월 $200~400)은 감내 범위로 보이나, FnGuide 계약·유료 데이터 전환 시점 판단에 필요하다.
4. 발간 전 **본인 검토에 주당 몇 시간**을 쓸 수 있는가? 세미오토 모델의 처리량 상한이 여기서 결정된다(어닝시즌 집중 부하 포함).
5. **미국 주식 확장**은 로드맵에 있는가? 있다면 EDGAR(퍼블릭 도메인)가 라이선스상 한국보다 자유로워 데이터 어댑터 인터페이스를 처음부터 추상화할 가치가 있다.
6. 조사 4의 비용·지연 수치는 전부 모델링 추정(±50%)이다 — 3~4주차 **10종목 파일럿 실측**을 로드맵의 go/no-go 게이트로 삼는 데 동의하는가?
7. KOSAI(kosai.kr) 실사를 최우선 태스크로 진행해도 되는가? 가장 유사한 기존 서비스인데 운영주체·품질·수익모델이 모두 미확인이다.
