## 5. 포지션 겹침 평가
**겹침 (상당함 — 직접 경쟁 요소 존재):**
- "미커버 커버리지 + 무료 + 일방향 발간 + AI 생성"이라는 표면 포지션은 KOSAI가 이미 점유. 코스닥·코넥스 전 종목을 무료·비로그인으로 커버하므로 **"미커버를 다룬다"는 것 자체는 차별화가 될 수 없음**.
- DART 정기보고서 제출 트리거 재작성은 "실적 리뷰"와 기능적으로 근접.

**차별점 (우리 포지션이 성립하는 지점):**
1. **검증 투명성**: KOSAI는 출처 URL 나열+기준 한 줄 표기 수준. **수치 단위 산식·각주 매핑, 자체 추정치, 추정 변화 추적은 전부 없음** — 재작성 시 이력이 사라지는 덮어쓰기 구조. "모든 수치 산식·출처 공개 + 추정 변화 추적" 축은 온전히 비어 있음.
2. **인간 검토**: KOSAI는 완전 자동화 명시 + 소스에 종목토론 게시글 혼입 등 품질 관리 공백. "인간 검토 후 발간"은 신뢰성 세그먼트에서 유효한 차별화.
3. **타이밍**: KOSAI는 정기보고서 제출 시점 재작성(분기 1회 수준). 실적 발표 직후 신속 리뷰 노트는 다른 시간대의 상품.
4. **깊이 vs 폭**: KOSAI는 2,683종목 균일 프로필(폭 전략). 선별 종목 심층 실적 리뷰(깊이 전략)와는 세그먼트가 갈림.

**종합**: 세그먼트 인접의 부분 경쟁. "미커버+무료"만으로는 KOSAI와 구분 불가하므로, 차별화 서사는 ②검증 투명성(산식·각주·추정 트래킹)+인간 검토+실적 직후 신속성에 집중해야 함. 단, 개인 운영 신생 서비스로 지속성·인지도 모두 미검증이라는 점도 참고.
