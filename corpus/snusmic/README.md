# SNU SMIC 리포트 코퍼스

서울대 학생 투자동아리 SMIC(snusmic.com)가 공개한 종목 리포트 아카이브.
"좋은 종목 리포트의 요건"을 역설계하기 위한 스터디용 코퍼스.

- **출처**: http://snusmic.com/research/ (WordPress REST API, 카테고리 `RESEARCH`)
- **수집일**: 2026-08-01
- **규모**: 777편 / 1.4 GB / **2007 ~ 2026년 (20년치, 연 40편 안팎)**
- **분량**: 편당 33~36페이지, 평균 2.3 MB

## 알려진 한계 — 반드시 읽을 것

### 1. 날짜: 게시일 ≠ 작성일

사이트는 2013-09에 과거 리포트 470여 편을 **일괄 업로드**했다. 게시일을 그대로 쓰면
최대 6년이 어긋난다. 다행히 구형 원본 파일명이 `111118_에스원_5팀.pdf`처럼
`YYMMDD` 접두를 갖고 있어 실제 작성일을 복원했다 (557편).

- 파싱된 날짜가 **전부 게시일 이하**라는 점이 복원의 타당성을 뒷받침한다
  (리포트가 게시보다 늦을 수 없음).
- 복원 전 연도 분포는 `2013년 276편`으로 심하게 왜곡돼 있었고,
  복원 후 `2007~2026년 매년 40편 안팎`으로 균일해졌다.
- 날짜 접두가 없는 221편(신형 `26_1_4주차_...` 형식)은 게시일을 그대로 썼다.
  최근 리포트라 게시 지연이 거의 없다.

### 2. 종목코드: 559/778 (71.9%)만 확보

`NA` 219건의 내역:

| 사유 | 건수(대략) | 설명 |
|---|---|---|
| 해외 종목 | 96 | Palantir, BYD, Aixtron 등 — 한국 종목코드가 원래 없음 |
| 산업/테마 리포트 | 27 | `조선 산업`, `자본시장통합법` 등 — 종목이 아님 |
| 상장폐지·사명변경 | 98 | 진로, 나우콤, 레인콤 등 20년 사이 사라진 이름 |

**정확도를 커버리지보다 우선했다.** prefix 매칭이 `현대차→현대차증권`,
`한국콜마홀딩스→한국콜마`, `SBS콘텐츠허브→SBS` 같은 **다른 법인**을 만들어내서
해당 규칙을 걷어냈다. 스터디 코퍼스에서 틀린 라벨은 `NA`보다 해롭다.

`match` 컬럼으로 자동추정분(`prefix`/`fuzzy` 9건)을 검수할 수 있다.
코드를 보정해도 **재다운로드 없이 즉시 재명명 가능** (`pdf_url`이 CSV에 있음).

소스: DART `corpCode.xml`(상장 3,981) + KRX 상장목록(2,703) 대조 확인.
KRX는 DART의 부분집합이라 커버리지 증가는 없었다.

## PDF 품질

스캔 이미지가 아니라 **정상 텍스트 레이어**. PyMuPDF로 전문 추출 가능.

```python
import fitz
doc = fitz.open("pdf/파트론_091700_Equity Research_2026-06-10.pdf")
text = "".join(p.get_text() for p in doc)
```

## 스터디 설계 시 주의

이 코퍼스는 **선별된 우수작이 아니라 SMIC 발간물 전체**다. 이 점이 오히려 장점이다.
"좋은 리포트만" 모아 읽으면 좋은 리포트의 요건이 아니라 그냥 리포트의 공통점
(투자의견·목표주가·밸류에이션 테이블)을 뽑게 되는 종속변수 편향에 빠진다.

우열을 가르려면 라벨이 필요하다:

- **A안 (잘 쓴 글)**: 사람이 논리·근거 밀도로 평가 → 주관적이지만 즉시 가능
- **B안 (맞춘 글)**: 리포트의 목표주가와 `date_report` 이후 실제 주가 경로를 대조
  → `src/arc/finmodel/backtest.py`로 검증 가능. 20년치라 표본이 충분하고,
  사람 판단이 아닌 **시장이 판정한 라벨**이라 반박하기 어렵다.

`doc_kind` 컬럼은 `수정보고서`(202) / `보고서`(14) / 미파싱(562)으로,
신형 파일명에만 존재한다. 사이트에 초안은 올라오지 않아 초안↔수정본 대조는 불가능하다.
